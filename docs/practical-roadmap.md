# Practical Roadmap

The source roadmap moves through:

1. HTML + CSS
2. JavaScript basics
3. Browser JavaScript
4. Modern JavaScript
5. Web communication
6. Backend
7. Database
8. Security
9. Deployment
10. Android
11. Advanced foundations

The source's practical mental model is: **learn one brick → build a tiny example → understand why it exists → connect it to the next brick.**

The goal is not to memorize every term. The goal is to understand how the pieces fit together well enough to build, inspect, debug and eventually design your own applications.
