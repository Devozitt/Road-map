# Backend and Database Notes

Node.js allows JavaScript to run outside the browser and is commonly used to build web servers and APIs. Express is a Node.js framework that helps create routes, middleware and API servers.

Backend responsibilities in the source include validation, authentication, authorization, business rules, database reads/writes, useful responses/errors, and keeping secrets and privileged operations away from the browser.

The source names relational databases such as PostgreSQL/MySQL and NoSQL databases such as Firestore/MongoDB. Core database ideas include CRUD, records/documents, tables/collections, identifiers, relationships, queries and indexes.
