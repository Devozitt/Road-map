# APIs and HTTP

An API is a communication interface between software components. On the web, frontend code often communicates with backend code through HTTP requests to API endpoints.

| Method | Typical purpose |
|---|---|
| GET | Read/retrieve data |
| POST | Create/submit data |
| PUT | Replace/update a resource |
| PATCH | Partially update a resource |
| DELETE | Delete a resource |

A request can contain a method, URL, headers and sometimes a body. A response contains a status code, headers and often data.

The source examples include 200, 400, 401, 403 and 404 status codes.
