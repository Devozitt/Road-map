# Deployment Notes

The source deployment flow is:

Write code → Test locally → Store/version with Git → Build the project → Deploy to hosting → Connect domain + HTTPS → Monitor errors and update.

Hosting provides a machine or cloud environment where the application can run and be reached over the internet.

A domain is the human-friendly name people type. DNS connects the domain name to the relevant internet service or server.

HTTPS uses TLS encryption to protect traffic between a browser and a website.
