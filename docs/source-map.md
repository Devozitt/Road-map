# Source Map

Primary source: **Web Development • From Zero — From Zero to Full-Stack Foundations**.

The source says the guide covers how websites work, HTML, CSS, JavaScript, APIs, frontend/backend, databases, security, hosting, and the path from a website to an Android app. It also says the order is intentional: learn the pieces first, then connect them into a real application.

Key source pages used by the website:
- Page 3: web layers and login journey.
- Page 4: HTML and CSS foundations.
- Pages 5–7: JavaScript basics, DOM/events, modules and modern concepts.
- Page 8: APIs, HTTP, JSON, fetch, request/response.
- Page 9: Node.js, Express, backend responsibilities and databases.
- Pages 10–11: security.
- Page 12: hosting, domains, DNS, HTTPS, deployment, environment variables, Git/GitHub.
- Page 13: website-to-Android approaches.
- Pages 14–15: practical learning roadmap and learning philosophy.
- Pages 16–17: glossary and PWA.
