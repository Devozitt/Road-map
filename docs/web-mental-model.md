# Web Mental Model

The source's central picture is:

User → Frontend → API / HTTP request → Backend → Database

The response travels back toward the user.

## Frontend
The frontend is the part running in the browser. It displays pages, buttons, forms, menus and animations. HTML, CSS and JavaScript are the core technologies.

## Backend
The backend runs on a server. It receives requests, checks permissions, performs business logic, talks to databases and sends results back.

## Database
A database stores information so it can be retrieved later.

## API
An API is a defined way for software systems to communicate. In a typical web application, frontend JavaScript sends a request to an API endpoint, the backend processes it and a response comes back.
